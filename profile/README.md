<h1 align="center">Daggry</h1>

<p align="center">
  <em>Start the work, go to sleep, and at first light it is done and checked.</em>
</p>

Daggry is a factory kit for unattended agent work. You set up its modules as your own factory: agents do the work, code checks every step, and each result is sealed in a signed evidence trail you can verify yourself.

- **The work is a file.** A workflow you can read and change: a plan, a test that fails first, an approval, a pull request.
- **Code checks every step.** Daggry never takes an agent's word for it.
- **Evidence you can verify.** Each run leaves a sealed record, checked by code instead of trusted on the agent's report.

*Daggry is Danish for dawn.*
